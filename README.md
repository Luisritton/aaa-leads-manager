# 🤖 AAA Leads & Automation Manager

Aplicação desenvolvida em JavaScript para gestão interna de leads, projetos de automação de IA e cálculo de faturamento previsto.

## 🚀 Tecnologias e Conceitos Aplicados
- **JavaScript (ES6+)**: Manipulação avançada de Arrays e Objetos Complexos.
- **Métodos de Iteração**: Uso de `.filter()`, `.map()` e `.reduce()` para processamento de dados.
- **Persistência de Dados**: Uso de `localStorage` com serialização e desserialização em JSON.
- **Validação & Log**: Execução e validação no Console do Desenvolvedor.

## 🛠️ Como Executar o Projeto
1. Clone este repositório para o seu computador.
2. Abra o arquivo `index.html` em qualquer navegador.
3. Pressione `F12` (ou clique com botão direito > Inspecionar) e acesse a aba **Console** para visualizar o relatório gerado em tempo real.
